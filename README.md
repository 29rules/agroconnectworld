# AgroConnect World

A full-stack B2B web platform connecting spice commodity suppliers with international buyers across UAE, Saudi Arabia, and Canada.

Built to support [Agronexus Trading](https://agronexustrading.in) — a real import/export business trading cumin, fennel, coriander, and sesame seeds.

## Features
- Product catalog for spice commodities
- - Buyer inquiry and contact workflow
  - - JWT authentication
    - - Mobile-responsive UI
      - - REST API backend
       
        - ## Tech Stack
        - - **Frontend:** React, JavaScript, CSS
          - - **Backend:** Node.js / Express
            - - **Database:** MongoDB
              - - **Deployment:** Vercel
                - - **Other:** REST APIs, Git, Docker
                 
                  - ## Project Structure
                  - ```
                    /frontend   - React application
                    /backend    - Node.js + Express API
                    /ops        - Deployment and config
                    ```

                    ## Getting Started
                    ```bash
                    git clone https://github.com/29rules/AgroConnectWorld
                    cd AgroConnectWorld/frontend
                    npm install && npm start
                    ```
